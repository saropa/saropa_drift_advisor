## B1. Semantic status tokens (`--error`, `--warning`, `--success`, `--info`) + a token lint

**Evidence.** `_themes.scss` defines no status colors. Result: 50 hardcoded hexes across 14 partials, seven different reds for one role — `#e57373` (`_data-table.scss:83,84,91`, `_sql-editor.scss:269,389`, `_schema-explorer.scss:126,127`, `_tab-bar.scss:164,212`, `_connection-banner.scss:17`), `#e53e3e` (`_history-sidebar.scss:119,374`), `#e15759` (`_settings.scss:240,241,251`), `#c62828` (`_tab-bar.scss:215`, `_themes.scss:205`), `#ef9a9a` (`_themes.scss:143`), `#b91c1c`/`#dc2626`/`#991b1b` (`_buttons.scss:36,38,49,54`). Warning ambers: `#ffb74d`, `#eab308`, `#e67e22`, `#e65100`. Greens: `#7cb342`, `#558b2f`, `#81c784`, `#276749`. Three status colors are invisible on light theme: `#ffb74d` on white 1.73:1 (`_schema-explorer.scss:131`), `#eab308` on white 1.92:1 (`_data-table.scss:276`), `#81c784` on white 2.01:1 (`_sql-editor.scss:379`). `#fff` hardcoded 6× where `--btn-primary-fg` exists.

**Change.**
1. Add to each of the four theme blocks: `--error`, `--error-bg`, `--warning`, `--warning-bg`, `--success`, `--success-bg`, `--info`, `--info-bg`, `--on-status` (text on a solid status background). Light values must reach ≥4.5:1 on `#ffffff` and `#f8faff` for the text tokens (e.g. error `#b42318`, warning `#b54708`, success `#2e7d32`, info `#2b6cb0`); dark/midnight values ≥4.5:1 on their `--surface`. Record the ratios in a comment next to each block.
2. Replace every hex listed above with the token. `grep -n "#[0-9a-fA-F]\{3,6\}" assets/web/_*.scss | grep -v _themes.scss | grep -v _base.scss` must afterward return only legitimately theme-independent values (pure white/black in the loading overlay, chart palettes) — list the survivors in the finish report with a one-line justification each.
3. Lint: add `stylelint` (dev dependency — blast-radius gate: get approval; alternatively write `assets/web/test/scss-tokens.test.mjs` that parses the partials as text) enforcing: no raw hex outside `_themes.scss`/`_base.scss`; every `var(--x)` references a property defined in those two files (this also pins `bugs/082`). Wire it into `npm run build:style` as a pre-step.

## B3. Animation and compositing cost in Midnight/Showcase

**Evidence.** `_theme-midnight.scss:34-53` and `:57-76`: two `position:fixed` 600×600 / 500×500 radial orbs animating `top`/`left` forever (layout every frame). `_theme-midnight.scss:22` and `_theme-showcase.scss:24`: `background-position` animation on `<body>` over a `400% 400%` gradient (full-viewport repaint, 20–25 s loop). `backdrop-filter`: 19 in showcase, 18 in midnight, 4 in `_tab-bar.scss`, 2 in `_toolbar.scss` — including scrolling `.data-table-scroll-wrap` (`_theme-showcase.scss:223`, `_theme-midnight.scss:279`) and sticky `th`/`td.col-pinned` (`:236,241` / `:292,297`). `_tab-bar.scss:141-152` blurs all of `#tab-panels`. Masked rainbow borders at `_theme-showcase.scss:96-125`, `_theme-midnight.scss:146-179` run infinite per expanded card. Uncovered by `prefers-reduced-motion`: `_tab-bar.scss:192` skeleton shimmer, `:235` busy spinner, `_sql-editor.scss:684` mic pulse, `_connection-banner.scss:20` reconnect pulse, `_theme-midnight.scss:161`, `_theme-showcase.scss:107`, `_cards.scss:156`.

**Change.**
1. Orbs: keep `top`/`left` static; animate `transform: translate3d()` only. Comment: transform is compositor-only; top/left forces layout.
2. Body gradient: replace the animated `background-position` with a static gradient plus one animated pseudo-element using `transform`/`opacity`, or drop the animation.
3. Remove `backdrop-filter` from `.data-table-scroll-wrap`, `th`, `td.col-pinned`, and `#tab-panels` in both themes; keep it on non-scrolling chrome (header, sidebar, flyouts).
4. Add the seven uncovered animations to the `_theme-effects.scss:59-78` reduced-motion block (or a new block in `_base.scss`), except the busy spinner, which may stay but should slow to a non-looping opacity change.
5. Add `--header-h: 57px` token in `_base.scss` and replace the five `57px` literals (`_layout.scss:47,48,187,188`, `_toolbar.scss:28,29`) and the mismatched `60px` at `_layout.scss:10`.

**Verify.** Chrome DevTools → Performance, Midnight theme, idle 5 s: no layout events in the flame chart; scroll a 1000-row table: no long frames from backdrop resampling. Note frame times before/after.

## B4. One button base; equal heights in mixed rows

**Evidence.** `.btn-primary` `min-height: var(--tap-min)` = 44px (`_buttons.scss:3`); secondary rule 36px (`:68-84`), repeated as a 5-selector list three times (`:68,86,97`); `.btn-danger` 36px; `.cell-value-popup-actions button` (`_data-table.scss:538-547`) is a verbatim copy; `.sql-result-copy button` 30px; `.cell-edit-retry` 28px; `.banner-btn` `3px` radius; `.search-nav button` `4px` radius; `.export-link` `--radius-sm` vs buttons `--radius-md`. Visible: Run (44px) beside Format (36px) at `html_content.dart:593-596`; same at `:641-644`, `:683-688`, `:697-702`, `:729-734`. Missing `:active` on all but `.btn-primary`; `.masthead-status` has no `:focus-visible`.

**Change.** In `_buttons.scss` define `.btn` (min-height `var(--tap-min)` on coarse pointers, 36px otherwise via the existing `pointer: coarse` pattern; `--radius-md`; token padding; `:hover`, `:active { transform: scale(.98) }`, `:focus-visible` ring) with modifiers `.btn--primary`, `.btn--secondary`, `.btn--danger`, `.btn--ghost`, `.btn--sm`. Migrate the copies to the base and delete them. Update class names in the shell and the TS emitters (grep each old selector before deleting). `.export-link` becomes `.btn .btn--secondary` styling on an `<a>`.

## B7. Typography tokens and the 12px floor

**Evidence.** 215 `font-size` declarations, 103 raw across 33 distinct values; `13px` appears 7× (`_data-table.scss:306,441`, `_sql-editor.scss:209`, `_schema-explorer.scss:34,43`, `_views-screen.scss:42`, `_data-display.scss:50`); `0.875rem` literal 6×. Below the project's own `--text-min-readable: 12px` (`_base.scss:25`): `_sql-editor.scss:375` 10px, `_schema-explorer.scss:115` 10.5px, `_history-sidebar.scss:134,188,211` and `_data-table.scss:48,57,89` 0.65rem, `_query-builder.scss:255,257,278`, `_sql-editor.scss:372`, `_schema-explorer.scss:153,167,191`, `_views-screen.scss:80` 11px. Ten distinct `line-height` values. Code surfaces missing `font-family: var(--font-mono)`: `_search.scss:2` (global `pre`), `_views-screen.scss:83`, `_data-table.scss:523`. `_sql-editor.scss:750` hardcodes `ui-sans-serif` for the Ask textarea (should `inherit`). Inline `style="font-size:11px"` in the shell at `html_content.dart:658,797,802,805,806`.

**Change.** Add `--text-13: 0.8125rem` and `--leading-tight: 1.25; --leading-normal: 1.5`. Replace every raw size with the nearest token; raise sub-12px to `--text-min-readable`. Move the shell's inline font sizes into classes. Add the mono token to the three code surfaces; fix `:750`. Extend the B1 lint to `font-size` and `border-radius` (allowed values: `var(--…)`, `inherit`, `1em`-relative for icons).
